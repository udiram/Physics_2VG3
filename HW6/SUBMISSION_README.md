# HW6 Submission Notes

This folder is set up so the main hand-in code is `rigidbody2d_seq.py`.

Default behavior:

- Running `python3 rigidbody2d_seq.py` starts on `scenario=5`, which is what the assignment asks for.
- You can switch scenarios with the command line using `--scenario 0` through `--scenario 6`.

Quick run examples:

- `python3 rigidbody2d_seq.py`
- `python3 rigidbody2d_seq.py --scenario 3`
- `python3 rigidbody2d_seq.py --headless --scenario 5 --duration 8.0`
